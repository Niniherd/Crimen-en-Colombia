# Crimen-en-Colombia
Large volumes of crime reports are generated every year, making it difficult to identify trends without a data-driven approach.
The goal is to transform raw crime data into actionable insights through data analysis, visualization, and predictive modeling.
# Business Objectives
Answer the following questions:

•	Which cities have the highest crime rates? 
•	Which crimes are increasing? 
•	What days and hours have the highest crime occurrence? 
•	Are there seasonal crime patterns? 
•	Which demographic groups are most affected? 
# Data Collection
https://www.datos.gov.co/
# Data Cleaning
The data was relatively clean, and no null values were found. However, some information was not reported and it was saved as "not reported". This is something we cannot simply remove or extrapolate, as doing so could introduce inaccurate assumptions.
Instead, the missing information will help us identify which data has not been collected and where there may be gaps in the data collection process.
